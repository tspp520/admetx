## DNS 配好之前的本地访问

**方式 A（推荐）— IP + 端口直连**：

```
http://10.1.170.84:3030     # prod web
http://10.1.170.84:3031     # dev web
```

要点：
- Next.js 必须 `-H 0.0.0.0` 启动
- 防火墙开 3030/3031（如开了 firewalld）

**方式 B — 本地 hosts + nginx**：

在你电脑 `C:\Windows\System32\drivers\etc\hosts` 加：
```
10.1.170.84  admetx.chempartner.com
10.1.170.84  admetx-dev.chempartner.com
```
然后访问 `https://admetx.chempartner.com`（wildcard 证书已生效）。
