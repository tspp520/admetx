## Postgres 实例

容器：`admetx-postgres`（postgres:16-alpine），监听 `127.0.0.1:5436`，`restart=unless-stopped`。

```
host:     127.0.0.1
port:     5436
user:     admetx
password: admetx_local
databases:
  - admetx_prod
  - admetx_dev
```

恢复命令（如果容器丢失）：

```bash
docker run -d --name admetx-postgres --restart unless-stopped \
  -e POSTGRES_USER=admetx -e POSTGRES_PASSWORD=admetx_local \
  -e POSTGRES_DB=admetx_prod \
  -p 127.0.0.1:5436:5432 \
  postgres:16-alpine
docker exec admetx-postgres psql -U admetx -d admetx_prod \
  -c "CREATE DATABASE admetx_dev OWNER admetx;"
```

数据持久化：当前未挂卷（重启容器数据保留，但 `docker rm` 会丢）。如要持久化，加 `-v admetx-pgdata:/var/lib/postgresql/data`。

## Pip 全局镜像

建议在 `~/.config/pip/pip.conf` 加：

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple/
```

## DATABASE_URL（最终用值）

```
DATABASE_URL=postgresql://admetx:admetx_local@127.0.0.1:5436/admetx_prod
DATABASE_URL=postgresql://admetx:admetx_local@127.0.0.1:5436/admetx_dev
```

`change-me` 已替换为 `admetx_local` 在 `.env.prod/.env.dev`。这是内网开发密码，可读，不进 git。
